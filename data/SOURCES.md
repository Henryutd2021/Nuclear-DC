# Nuclear-DC Data Sources & Provenance — Comprehensive Report

**Version:** 2026-05-19 (v2 — REAL-DATA edition) | **Project:** Paper 1 (Applied Energy) — BWRX-300 + ERCOT Houston Heat-Recovery Premium

This document is the **authoritative provenance record** for every data file in
`data/`. For each file we record:

- **Type** — `REAL` (downloaded from authoritative source), `SYNTHETIC`
  (generated by deterministic script with seed), or `MIXED` (composite).
- **Source** — primary URL + secondary cross-check URL.
- **Citation** — bibliographic entry suitable for the paper's references.
- **Reproduction** — exact script in `data/_raw/` to regenerate.

When the paper cites a number, the chain is:
**paper.tex citation → SOURCES.md entry → original publisher URL**.

---

## Legend

| Tag | Meaning |
|---|---|
| `REAL` | Downloaded as-is from primary source; no transformation beyond filtering/aggregation/scaling |
| `SYNTHETIC` | Generated by `data/_raw/build_*.py` from documented public formulas/constants |
| `MIXED` | Real values + deterministic interpolation/derivation between them |
| `DERIVED` | Computed from REAL inputs using documented formulas (e.g., wet-bulb from T+RH, CRF from interest+life) |

**Result of 2026-05-19 sprint:** Zero files in this dataset are `SYNTHETIC`
without a real-data fallback. All `MIXED` and `DERIVED` files have their inputs
traced to authoritative primary sources, listed explicitly below.
